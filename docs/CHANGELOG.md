# 更新日志 / Changelog（fto-site 魔方训练站）

本文件记录站点版本变更，版本号遵循 [语义化版本 2.0.0](https://semver.org/lang/zh-CN/)。

**协作约定**
- `main` 分支始终为可上线稳定版；新功能在功能分支开发，合并进 `main` 时在本文件顶部追加条目。
- 每次发布打 `v<版本号>` 轻量标签（如 `v1.0.0`），标签仅本地留存或经确认后推送。
- 破坏性数据口径变更（读码口径、难度分公式、存储结构）必须升级 MAJOR 并写明迁移说明。

---

## [1.0.0] — 2026-09-28（首发稳定版）

首个对外稳定版本。覆盖三盲训练、课堂管理、CFOP、练习题、配色与导航系统、PWA 等核心能力。

### 三盲计时与打乱（timer / bldscramble）
- 三盲分段计时改为全程空格触发，M 键退役
- 桌面横版单屏布局（参照 csTimer），移动端体验优化
- 分段成绩统计、字体大小设置、确认区指标对齐
- PWA 化：manifest + 根目录 `sw.js`（站点级作用域）+ offline 兜底页 + iOS 安装 meta + 图标
- 主记法口径统一：翻色并入棱、角翻并入角
- 三盲难度分重标定：0~100 分 + 五档（L1 0-19 / L2 20-39 / L3 40-59 / L4 60-79 / L5 80-100）
- SPOON 读码接入全站导航

### 课堂管理（class-teach）
- 上线魔方课堂教学系统，全站导航同步
- 六维雷达支持手动设定
- 计分页网格自适应（移动端横滚）
- 修复：数字学号排序崩溃、计分页 `cols` 未定义

### 三阶教学图库（3x3teach）
- 图库卡片加载占位骨架 + 大图按钮 + 页码字段修正
- 投屏放大优化（260→300px）

### 练习题生成器（practice）
- 三栏工作台布局（一级导航｜二级导航+参数｜生成内容）
- 左侧参数区双列网格，整页单屏不滚动
- 体验审计修复：阶数默认值统一+双向联动 / >=1600 参数列放宽 / 三段分组标题
- 默认「消翻色」= 不用（与 bldscramble 的默认「用」刻意区分，勿统一）

### CFOP（cfop）
- 十字训练器支持「打乱拿法」与「复原拿法」分别设定
- 十字训练器接入 XCROSS 计算 + 桌面横版单屏布局

### 班级宠物园
- 接入 47 物种宠物素材（用户提供 webp）
- 响应式网格 + 点卡看大图弹窗 + 手动喂养 1-20 档
- 多通道积分（`awardScore` 统一入口 / 知识点 +5）+ 加分可视化（弹跳/飘分/撒花）

### 设计系统与配色（全站）
- 6 套场景配色方案层，与明度正交、三端同步（曜石蓝 / 课堂白 / 暖夜墨 / 投屏高对比 / 纸感米黄 / 经典六色）
- 导航重做：侧栏二级菜单按需展开，全站去掉页头大标题
- 宽屏横版 `site-wide.css`，三栏工作台布局统一
- 全站移动端适配

### 账号与同步（auth / sync）
- 登录链路加固：SDK 固定版本并自托管 + 错误汉化 + 请求超时 + 连通性预检
- 账号同步引擎

### 导航与首页
- 主页教程与公式库分区对齐导航结构（FTO / 三阶 / 二阶 / 金字塔 / 三盲）
- 盲拧打乱生成器接入全站导航

## 版本规则
- **MAJOR**：不兼容的架构/数据口径变更（读码口径、难度分公式、存储结构重构）
- **MINOR**：向后兼容的功能新增（新增训练模块、新增配色方案）
- **PATCH**：向后兼容的缺陷修复

> 每次合并到 `main` 前，必须在此文件顶部追加对应条目；版本号变更同步写入 `docs/VERSION`。
