# 更新日志 / Changelog（fto-site 魔方训练站）

本文件记录站点版本变更，版本号遵循 [语义化版本 2.0.0](https://semver.org/lang/zh-CN/)。

**协作约定**
- `main` 分支始终为可上线稳定版；新功能在功能分支开发，合并进 `main` 时在本文件顶部追加条目。
- 每次发布打 `v<版本号>` 轻量标签（如 `v1.0.0`），标签仅本地留存或经确认后推送。
- 破坏性数据口径变更（读码口径、难度分公式、存储结构）必须升级 MAJOR 并写明迁移说明。

## [2.0.1] — 2026-10-10（补丁 · 同步防丢数据）

> 紧急修复：同步引擎的 LWW（后写覆盖）逻辑会把「空数据」当成合法的较新版本，
> 一旦某一端为空且时间戳较新，就会把另一端（有数据的）覆盖成空。
> 本次修复前曾导致电脑 / 手机两端成绩被互相清空。

### 同步引擎（数据不再互删）
- **空覆盖铁律**：`pullScope` / `pushScope` 新增 `snapEmpty` / `remoteEmpty` 判定；
  一端有数据、另一端为空时保留有数据的一方（`emptykept`），不再用空覆盖非空。
- 同步面板「高级」新增两个显式按钮：**用本机覆盖云端** / **用云端覆盖本机**
  （仅在用户确认时执行，带二次确认，绕过空覆盖保护）。
- 计时器 `timer.js` 监听 `sync:status`，同步下载后**自动重读列表**，无需手动刷新。
- `ls-provider.js` 透传 `isEmptySnap`；`tools/timer/index.html` 注册内容级空判定
  （只统计 `timer_data_v2` 三项 solves 总数，忽略 options 键以免保护失效）。

### 验证
- 单元测试 `test-empty-guard.js` 10/10；账号同步 UI 回归 `account-sync-ui-verify.py` 36/36；
  同步刷新 e2e `verify-sync-refresh.py` 5/5；计时器布局回归 `verify-timer-cstimer.py` 全过。

## [2.0.0] — 2026-09-30

> 版本号已定稿为 **2.0.0**：本版含「三盲难度分公式」口径变更，按本文件顶部约定属 MAJOR。
> 跨版本注意：同一把打乱在新旧口径下的**难度分与档位不可直接比较**；历史成绩按分量自动重算，无需手工迁移。

### 三盲难度分（口径修正 · 翻色权重首次压过奇偶）
- 难度权重 `翻色 1.5 / 奇偶 4.0` → **`翻色 3.0 / 奇偶 2.5`**：同条数下「无奇偶 + 翻色」高于「带奇偶」，与实战体感一致
- 锚点按 3000 个新样本重新取分位：`7→0 / 12→20 / 14→40 / 16→60 / 18.5→80 / 27→100`，五档实测占比 18/19/18/24/21
- 说明页 `tools/3bld/level.html` 全面同步（公式、权重表、分档构成表、样例对照、新增 FAQ）
- 旧成绩仍按分量自动重算（`E.recalcDifficulty()` 路径），**无需手工迁移**；但跨版本分数不可直接比较，同把档位可能变化一级

### 三盲复盘分享海报（timer）
- 成绩详情面板新增「生成分享海报」：一键生成 1080 宽 PNG，含用时、难度档、打乱公式、解法编码（坐标/棱/翻色/角/扭/主记法）、分段指标、练习笔记
- 手机优先调用系统分享（`canShare({files})`），桌面/不支持时兜底预览层 + 「保存图片」
- 海报配色**跟随当前生效的站点主题与配色方案**（6 套配色 × 明暗两态各自成图）：色值全部取自生效 CSS 变量并做混色派生（品牌强化版深底提亮、浅底压深），对比度沿用设计令牌的校正结果
- 颜色承担信息分类：顶部品牌→紫→金三段渐变、用时品牌→紫渐变字、难度档色阶（L1 绿 → L5 红）、编码类别色（棱蓝 / 翻色金 / 角绿 / 扭紫）、分段指标四格四色、笔记琥珀边条
- 打乱公式改等宽字体 + 金色语义（站点「公式 / 重点」色）；按内容自适应高度，底部不空

### 计时器 PWA 缓存
- `sw.js` 缓存版本 `fto-timer-v3` → `fto-timer-v4`：本版改动 `timer.js` / `timer.css`，而静态资源走 stale-while-revalidate（cache-first），不递增版本会让已安装的 PWA 首次打开仍用旧脚本/样式（旧海报配色），第二次才更新。约定：**凡是动到 `APP_SHELL` 清单里的文件都要递增该版本号。**

### PWA 图标（timer 手机桌面）
- 新图标：等距魔方 + 计时环（环带缺口与表冠），矢量母版入库 `assets/icons/timer-app-icon.svg`
- 输出 `icon-192 / icon-512 / icon-maskable-512 / apple-touch-icon(180)`；maskable 美术缩至 84% 落在安全圆内
- `sw.js` 缓存版本 `fto-timer-v2` → `fto-timer-v3`：已安装的 PWA 会丢弃旧图标缓存

### UF/UR 公式训练页（练习界面 · 工作台改造）
- 40 个 group 练习页对齐计时器页视觉：页头 hero + 拿法坐标系工具栏 + 桌面横版两栏铺满
- 右栏大号计时舞台（超大时间数字、空格/点按起停、红/绿/蓝状态着色）+ 参考公式面板与 KPI
- 三端适配：≥1025 两栏 / 768~1024 单栏 / ≤640 大计时按钮无横向滚动
- 样式抽到共享 `assets/css/practice.css`，颜色全部收口设计令牌（修掉旧硬编码蓝）；新增 UR 生成器 `gen_ur_html.py`

## 版本规则
- **MAJOR**：不兼容的架构/数据口径变更（读码口径、难度分公式、存储结构重构）
- **MINOR**：向后兼容的功能新增（新增训练模块、新增配色方案）
- **PATCH**：向后兼容的缺陷修复

> 每次合并到 `main` 前，必须在此文件顶部追加对应条目；版本号变更同步写入 `docs/VERSION`。
