## 一、版本概览

站点代号 **fto-site**（魔方训练站），面向魔方教学与自学场景，是一个纯前端 + 云存储（Supabase）的静态站，部署于 GitHub Pages。本期（Q3）从零散工具页演化为统一工作台形态：

- **导航骨架**：左侧常驻导航 + 右侧主体，全站去掉页头大标题。
- **布局范式**：三栏工作台（一级导航｜二级导航+参数｜生成内容），桌面横版单屏、移动端响应式。
- **设计系统**：统一设计令牌（tokens.css）、6 套场景配色层（与明度正交）、变体按钮规范。
- **可安装性**：PWA 化（manifest + 站点级 Service Worker + offline 兜底）。
- **账号体系**：Supabase 登录加固（SDK 自托管 + 错误汉化 + 超时 + 连通性预检）。

## 三、架构与设计系统要点

- **设计令牌唯一来源**：`assets/css/tokens.css`；页面内联 `<style>` 禁止复现主题变量，覆盖靠「后加载 + 更高特异性」，页面零改动。
- **配色层选择器铁律**：必须写 `html[data-palette="x"]`（特异性 0-2-1），否则被上游 `@import tokens.css` 压掉。
- **三盲引擎口径（权威）**：字母表 = A–Z 去 U/V（24 个）；SPOON 读码逻辑唯一来源 `bld-scramble-core.js`，页面内禁止复制；难度分公式 `raw = 条数 + 3.0×(翻色+扭角) + 2.5×奇偶 + 0.5×借位`，锚点 7→0 / 12→20 / 14→40 / 16→60 / 18.5→80 / 27→100（2026-09-30 口径修正：翻色权重首次压过奇偶，文档同步页 `tools/3bld/level.html`）。
- **KPI 口径**：mea 门槛 `ceil(n/2)`，有效把数不足显示 `—`；参数区间 `parseRange` 识别不了返回 `{invalid:true}`，绝不静默当不限。

## 四、质量与验证

- 已建立本地验证栈：自包含起服务（ThreadingTCPServer 后台线程）+ Playwright 断言，脚本在 `.workbuddy/outputs/`。
- **核心教训（本地 ≠ 线上）**：`verify-radar-manual.py` 本地 26/26 全绿，却漏掉 `students()` 对数字学号调 `localeCompare`（整页 TypeError）和 `scoreCellSize` 的 `cols is not defined`。**回归脚本全绿 ≠ 功能可用，断言必须覆盖真实点击路径（学生列表 / 计分页）**。
- 线上抽样为硬性门禁：每次推送后等约 85s 让 Pages 构建完，再跑线上实机验证。

## 五、已知风险与待办

1. **360 安全卫士可能删除 `.git` 内容**（不留日志）→ 每次上线前必须 `robocopy` 快照 `.git`（已建周自动任务）。
2. **`origin/main` 远端引用偶发写不进**：`git status` 的 ahead 计数可能是假象，判断已推送要用 `git ls-remote` 对比 HEAD，别信本地 status。
3. **仓库内存在一处 JWT/密钥形态串**（疑为 Supabase 公开 anon key，按 RLS 设计本应公开）——已因系统敏感策略中止扫描，需人工确认非 `service_role` 私有密钥；若误提交私有密钥须立即轮换并清历史。
4. **宠物素材与预览页**：`assets/pets/*.png`（40 张）+ `_design/pet-preview.html` 在 1.0 纳入版本库（本次提交）。
5. **禁止 `git rebase`**（已两次致命）；合远端走 `git fetch` + `git merge --no-ff`。
