怎么用

3
从 J（黄绿红）的位置起笔读码，读出来应该正好是上面这串。
读码规则 在角位的高位（U/D 面）看贴纸是哪个字母，就走到那个字母所属的角位继续读； 读到缓冲块 J 就收尾，不写这个字母。 循环断了按 G → D → A → W → O → R 的顺序借位。 角块原位但翻了要写两个字母：DE 表示 DEF 那个角的高位显示 E（顺翻）， DF 表示显示 F（逆翻）。
字母表 按「绕角一圈」排列，第一个字母在 U/D 面
借位顺序
缓冲块 J（UFR 黄绿红）；定位块 XYZ（DFR 白红绿），摆正后它在原位，所以编码里不会出现 X / Y / Z。
