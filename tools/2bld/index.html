为什么位置和扭角要分开写？ 如果直接按贴纸读循环，一次扭角就会把链拉得很长（实测同一个状态要 15 个字母）。 本工具先把每个角在位置上「摆正」再读位置循环，长度必然 ≤ 7；扭角另外用字母对标出。 两段合起来才是完整编码，打乱后你按自己的习惯读，两段都会对上。
字母表 缓冲块 UFR（J）
位置编码：从缓冲 J 开始追踪，每遇到一个块就记下它高色贴纸的字母。例如 XRG 表示 UFR → DFR → DBR → UBR → 回到 UFR。多段循环用 - 隔开。
缓冲块自己归位时，循环从下一个未读的块起笔——这种编码和「缓冲参与」的编码写法会撞车 （D 既可能是 J↔D，也可能是 G↔D），所以请勾选输入框下的 「这一把的缓冲块 J 已经归位」，工具才知道该按哪种读法解。
扭角：写成「角位字母 + 扭数」，J1 表示 UFR 位置的角扭了 1 次，J2 是 2 次。 也可以写角位名 UFR1，或用字母对 JK（等价于 J1）。 二阶的扭角总和必须是 3 的倍数，所以单个角扭 1 次是不成立的，工具会直接提示。
