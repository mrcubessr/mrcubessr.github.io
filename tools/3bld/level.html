三盲难度分级标准

计时器 / 复盘里那枚「难度分」是怎么算出来的、五档是怎么划的，全部写在这一页。 一句话概括：难度分是 0~100 的分数，先看要背多少条公式，再看翻色、奇偶、借位。

一、为什么要重做这套分

旧版的分数几乎全都落在 10~20 这一段，看不出层次。原因不是权重没调好， 而是被一个事实卡住了：

实测 3000 个 20 步 WCA 打乱：总公式条数的四分位区间是 10~11（最少 7 条、最多 13 条）。 也就是说，条数本身几乎是个常数，真正拉开难度的是翻色、奇偶和借位。

所以这版做了两件事：① 把翻色 / 奇偶的权重提上去；② 把分数重标定到 0~100， 并按实测分布划成五档，让每档各占约两成，不再挤成一团。

二、难度分怎么算

第 1 步｜算「加权分」（量纲≈条数，范围约 7~27）

加权分 ＝ 公式条数 × 1.0
＋ （翻色条数 ＋ 角翻条数）× 1.5
＋ 奇偶 × 4.0
＋ 借位处数 × 0.5
项目权重说明
公式条数1.0第一权重。棱 + 角 + 翻色 + 扭角 + 奇偶的公式总条数（翻色 / 扭角 / 奇偶本身也各算一条）
翻色 / 扭角+1.5 / 条除公式本身，还要多记 setup 与额外记忆点，所以在条数之外再加成
奇偶+4.0单独一套奇偶算法，外加「判断这一把有没有奇偶」的负担
借位+0.5 / 处借位 = 循环数 − 1（第一个循环不用借）。循环越多，记忆切换越频繁

注意：翻色、扭角、奇偶已经各自算进「公式条数」里了，上表的权重是额外加成。 所以一条翻色公式的实际分量是 1 + 1.5 = 2.5，一次奇偶是 1 + 4 = 5。

第 2 步｜加权分 → 难度分（0~100）

用一组固定锚点做分段线性映射，锚点之间按比例插值：

加权分难度分含义
≤ 70理论最轻松的一把
1220L1 / L2 分界（实测 20% 分位）
1440L2 / L3 分界
1660L3 / L4 分界
1880L4 / L5 分界
≥ 26100理论最难的一把

这些锚点取自实测分布的分位点（20% / 40% / 60% / 80%），目的是让五档各占约两成，不会出现「高难档永远空着、低难档挤满」。

五、常见问题

为什么我以前的成绩，等级突然变了？
旧成绩存的是旧权重、旧七档（入门 / 初级 / 中级 / 中高级 / 高级 / 专家 / 大师）。 打开页面时会按新口径自动重算，所以同一把的档位可能变了一级。 重算只依赖棱 / 角 / 翻色 / 扭角 / 奇偶 / 借位这些分量，旧数据全都带着， 因此不需要重新练一遍，历史统计也还是连续的。
难度分和公式条数是什么关系？
条数是第一权重，直接进分数；翻色、奇偶、借位是在条数之上的加成。 两把条数相同的打乱，翻色 / 奇偶多的那把分数明显更高（见上面样例）。
为什么最高档叫「专家」而不是「大师」？
旧版有七档，但最高的「大师」档在 3000 把实测里只出现过 1 次，等于空设。 现在改成五档，每档都有足够的样本量，分组对比才有意义。
这个分能跨人比较吗？
能，前提是读码口径一致（缓冲、借位顺序、翻色处理方式相同）。 分数只由打乱本身的编码结构决定，和你练得多好、用哪套公式无关。

六、在哪能看到难度分

  • 计时器 · 三盲模式：解法面板下方显示「共 N 条公式 · 难度分 XX / 100」和 L1~L5 档位徽章，旁边有本页入口。
  • 成绩列表：每条三盲成绩附带条数与档位。
  • 统计分析：「⑤ 按难度等级分组」按五档横向对比用时与 TPS，并给出每档平均难度分。
