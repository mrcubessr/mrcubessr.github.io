# CFOP 公式库 · 复刻整合设计方案

> 目标站点：https://www.speedcubedb.com/a/3x3
> 复刻范围（用户指定保留）：**F2L · Advanced F2L · OLL · PLL**，以及下方的 **Cross Trainer**
> 落地站点：本地 `fto-site`（魔方先生SSR训练中心），完全复用既有设计系统

---

## 1. 目标站点分析

| 页面 | 路由 | 内容 | 数据形态 |
|---|---|---|---|
| F2L | `/a/3x3/F2L` | 41 个 case，每 case 含 FR/FL/BL/BR **四朝向**算法 | 子页 `/a/3x3/F2L/F2L_1` 即含全部 41 case，每 case 4 朝向按 `data-t="F2L N,0..3"` 切分 |
| Advanced F2L | `/a/3x3/AdvancedF2L` | 54 个 case（Trapped Corner / Edge / Both），社区多算法 | 单页完整（1.98MB） |
| OLL | `/a/3x3/OLL` | 57 个 case，按形状分类（Dot/L/T/鱼形…） | 单页完整（57×4 算法） |
| PLL | `/a/3x3/PLL` | 21 个 case（含 AUF） | 单页完整（21×4 算法） |
| Cross Trainer | `/cross` | 交互训练器：随机打乱 + 计时 + 3D 可视化链接 | 无静态数据，需本地生成 |

**关键发现**：所有算法都内嵌在页面 HTML 的 `<div class="cubedb-ftw-" data-alg="…">` 与 `.formatted-alg` 节点中，可作为**精确数据源**离线抽取（无需手抄，零误差）。

## 2. 本地化（下载→解析）方案

`tools/cfop/scripts/fetch_cfop.py`（及专用 `fetch_f2l.py`）：

1. 请求目标页面原始 HTML；
2. 按 `<div class="row singlealgorithm">` 切分案例；
3. 提取 `data-alg`(编号)、`data-subgroup`(分类)、`setup-case`(还原打乱)、`.formatted-alg`(算法文本)；
4. F2L 每个 case 含 4 个朝向 `<ul class="list-group" data-t="F2L N,0..3">`，按 `data-t` 切分 FR/FL/BL/BR 四朝向；
5. 提取案例配图数据：OLL/PLL 取 `jcube` 的 `data-us/ub/uf/ul/ur`（→ `facelets`），F2L/AdvF2L 取 `icube` 的 `data-fl`（→ `fl`，见 `enrich_cubedata.py`）；
6. 输出结构化 JSON：`tools/cfop/data/{f2l,advanced_f2l,oll,pll}.json`。

数据已生成：OLL 57 / PLL 21 / AdvancedF2L 54 / F2L 41（四朝向齐全，共 622 条算法，0 残存 HTML）；
配图数据：OLL 57 / PLL 21 含 `facelets`，F2L 41 / AdvancedF2L 54 含 `fl`。
**重新更新数据**：`python tools/cfop/scripts/fetch_cfop.py`（或逐个 `fetch_f2l.py`），随后 `python tools/cfop/scripts/enrich_cubedata.py` 补配图数据。

## 3. 站点整合架构

完全复用既有设计系统（阶段三已交付），**不引入新框架、不写死颜色**，所有视觉走 `tokens.css` 变量。

```
tools/cfop/
├── index.html              # 总览 hub（卡片导航）
├── f2l.html               # F2L 41 cases（四朝向 tabs）
├── advanced-f2l.html      # Advanced F2L 54 cases
├── oll.html               # OLL 57 cases（顶面示意图）
├── pll.html               # PLL 21 cases（顶面示意图）
├── cross-trainer.html     # 交互训练器
├── css/cfop.css           # 页面专属样式（仅用 token）
├── js/cube-art.js         # 案例配图渲染器（顶面示意图 / 等轴立体魔方，复刻原站）
├── js/cube3d.js           # 3×3 立体渲染器（正投影 + 背面剔除 + 画家算法，供十字训练器）
├── js/cfop-ui.js          # 共享渲染器（搜索/筛选/朝向/复制/进度/主题）
├── js/cross-trainer.js    # 自包含 3×3 模拟器 + 立体视图 + 计时（可拖拽旋转）
├── data/*.json            # 抽取的真实算法数据
└── scripts/               # 下载/解析脚本 + 单元测试
```

加载顺序（遵循站点约定）：`site-nav.css` → `components.css` → `site-layout.css` → `cfop.css`；
导航通过 `assets/js/site-nav.js` 的 `NAV_DATA` 新增顶级项 **「CFOP公式库」→ /tools/cfop/**。

> 原 `tools/3x3/` 下的旧版自研 F2L 参考页（272KB）已**删除**（用户确认不再需要）；`tools/3x3/` 现为三阶总览 hub，指向 `tools/cfop/` 各页。

## 5. 数据模型（JSON）

```json
{
  "set": "oll",
  "count": 57,
  "cases": [
    {
      "id": "OLL 1",
      "subgroup": "Dot Case",
      "setup": "",
      "facelets": { "us":"llllyllll", "ub":"…", "uf":"…", "ul":"…", "ur":"…" },
      "orientations": [ { "name": "", "algs": [ "R U2 R2 F R F' U2 R' F R F'", "…" ] } ]
    }
  ]
}
```
- F2L 的 `orientations` 有 4 项（FR/FL/BL/BR），其余集合为 1 项；
- `facelets` 仅 OLL/PLL 有（5 面 jcube 数据）；
- `fl` 仅 F2L / AdvancedF2L 有（45 字符 icube 数据：顶面 + 两可见立面 + 两隐藏面）。

### 案例配图（复刻原站 speedcubedb，`js/cube-art.js`）

原站的案例图由前端渲染，本地按其投影算法等价实现，**不使用六面展开图**：

| 集合 | 原站渲染器 | 数据 | 本项目渲染 |
|---|---|---|---|
| OLL / PLL | `jcube`（`data-us/ub/uf/ul/ur`） | `facelets` | **顶面平面示意图**：中央 3×3 顶面 + 四周一圈侧面顶层贴纸（上=ub 下=uf 左=ul 右=ur） |
| F2L / Advanced F2L | `icube`（`data-fl`，45 字符） | `fl` | **等轴立体魔方**：顶面 + 左/右两个可见立面（bilinear 投影，贴纸按面行主序） |

- 配色统一走 `tokens.css` 的 `--face-*` 六面色（`y→D 黄 / w→U 白 / g→F 绿 / b→B 蓝 / r→R 红 / o→L 橙`，`l` 为中立灰），随深浅主题自动切换；
- 等轴投影的四边形顶点取自原站 `svg.js` 输出，41 个 F2L 案例已与原站 SVG **逐格比对 0 偏差**；
- 数据补齐脚本：`scripts/enrich_cubedata.py`（从 `data/_raw/` 的原始 HTML 提取 `fl`）。

## 6. 交互功能（已落地）

- **全局搜索**：按编号 / 分类 / setup 实时过滤；
- **分类筛选**：点击 subgroup chip 快速定位（如 OLL 的「鱼形 / Dot」）；
- **F2L 朝向切换**：FR/FL/BL/BR 标签页切换；
- **点击复制**：算法与 setup 一键复制（含「已复制」反馈）；
- **掌握进度**：localStorage 持久化「★已掌握」，顶部进度条统计；
- **深浅主题**：与全站 `data-theme` 同步，记忆偏好；
- **Cross Trainer**：本地生成 22 步打乱 → 自写 3×3 模拟器 → `cube3d.js` 渲染**立体魔方**（默认从下往上看，底面朝向观察者，可拖拽旋转）→ 空格键计时 → 一键跳转 cubedb.net 看 3D。

---

## 7. Cross Trainer 设计

- **打乱生成**：`U/D/L/R/F/B` 随机，避免同面连发，约 22 步；
- **可视化**：纯前端 facelet 模拟器（已通过 8 项单元测试：单步与逆步互逆、四次幂还原、30 步乱序+逆序还原），由 `js/cube3d.js` 渲染**立体魔方**（正投影 + 背面剔除 + 画家算法，非展开图）。
  - 默认视角**从下往上**（yaw −45° / pitch −40°）：**底面朝向观察者**，底层十字一目了然；
  - **可拖拽旋转**（鼠标 / 触摸），转到任意角度即可看到全部 6 面，兼顾了"必须看全 6 面"的训练需求；
  - 投影正确性已用还原态断言（俯视=白、仰视=黄、正视=绿）。
- **计时**：`requestAnimationFrame` 精确计时，空格开始/暂停；
- **3D 链接**：`https://www.cubedb.net/?puzzle=3&scramble=…`（与官网一致，无需自带 3D 引擎，离线也可用 2D 图）。

## 8. 后续可扩展

1. **可旋转 3D 公式图**：接入 `cubing.js / twisty-player`，让案例配图（现为静态等轴图）支持鼠标拖拽旋转；
2. **算法「更多变体」**：脚本已抽取标准+备选，可加「显示全部 / 仅标准」切换；
3. **个人训练模式**：基于掌握进度生成「薄弱 case」抽认卡；
4. **PWA / 离线**：data 已本地化，加 manifest 即可离线使用；
5. **移动端**：网格自适应已就绪（`auto-fill, minmax`），无需额外工作。
