FORMULA TRAINER

公式训练器

选一个缓冲块，剩下两个位置的排列组合全部自动进矩阵 · 六套体系一处练

怎么用

1
选缓冲块
24 个字母任选其一（默认记住你上次的选择），页头显示它的位置名。
2
矩阵自动展开
其余 23 个字母组成 23×23 矩阵，每个有效格子就是一条公式，点开即练。
3
计时 + 统计
按住空格 0.5 秒起表，停表自动记录；看板按快慢着色，最慢的自动排前。
4
公式写法三选
工具条「显示」里选：展开式 / 括号格式 / 两者都显示。高阶四个体系（角心 / 翼棱 / 棱心 / 中棱） 的括号格式是 [A,B] 交换子、A:[B,C] 共轭，一眼看清公式怎么组成的。
5
★ 标记母公式
每张卡片右上角有个星标：点一下就把这条标成「母公式」（基础转换机，其他公式由它变化而来）。 点开卡片的练习浮层里，公式下方就是标记行——五档颜色（母公式 / 重点练 / 易错 / 已掌握 / 自定义）直接点选，备注直接写，不必再进详情。
6
矩阵坐标 / 标记筛选，选练法
最方便的是直接点矩阵左侧的行标、顶部的列标——点一下就只看那一行 / 那一列， 可多选（行 ∪ 列取并集），再点一次取消，工具条会显示当前锁定状态； 筛选下拉还能只看未练 / 已标记 / 母公式；练习模式可选「单次计时」或「连做三次取平均」。
