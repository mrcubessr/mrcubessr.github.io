记忆卡片 · SRS

基于 SM-2 间隔重复算法，用来记联想词和自建公式卡组。数据存在本机浏览器，不上传。

怎么用

1. 「三盲联想词」预置牌组已按字头拆成 A 组 / B 组 / C 组… 等独立小组，每组单独计进度，点开「三盲联想词」分组挑一组练，不用再面对一大堆混在一起的卡。
2. 联想词为单向考核：看到字母代码 → 在脑子里回忆联想词（不做选择题，避免被提示）；翻面核对后给 4 档评分。
3. 公式类卡组自己建：新建牌组 → 进入编辑页，用「范围生成」按棱块/角块 + 首字母批量建卡，或整段粘贴录入。
4. 全程键盘操作（鼠标可完全不用）：空格/回车 翻面看答案，看答案后 空格 = 记住并下一张，1 重来 / 2 困难 / 3 良好 / 4 简单，Esc 退出。
